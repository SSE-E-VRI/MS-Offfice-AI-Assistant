AI Assistant for Microsoft Office — User Manual

Version 0.5.0  |  Applies to Word, Excel, and PowerPoint (Office 2010 – Microsoft 365, 32-bit and 64-bit).

Designed and developed by D.Manikandan B.E, SSE/E/VRI, Mob No 9444861302.

Before you start. The AI Assistant never changes your document silently. It proposes changes as text, cards, or previews, and every native Office edit is applied only after you confirm it. Use the Context scope dropdown in the panel to choose exactly what text leaves your PC and is sent to the AI provider. The assistant is a drafting and analysis aid — it does not replace the responsible human reviewer.

1. Features available

The AI Assistant is a Bring-Your-Own-Key (BYOK) add-in. You supply an API key for the AI provider of your choice; the add-in connects directly to that provider and stores your key and data locally and encrypted.

What the assistant can do

  • Streaming chat — type a prompt, or click a ribbon/quick button, and see the answer appear live in the panel.
  • Attachments — attach .docx, .xlsx, .pptx, .pdf, images (.png/.jpg/.jpeg/.webp/.gif), and text files (.txt/.csv/.json/.md). Image attachments are sent only to models that support vision; otherwise they are skipped with a note. Legacy .doc/.xls/.ppt/.rtf files are rejected.
  • Context scope — decide per prompt what is sent: Selection, Current file, Selection + file, or Attachments only.
  • Chat / Plan / Edit modes — a mode selector next to the model dropdown controls what the AI is allowed to do. Chat is Q&A only and never touches the document. Plan turns a request into an ordered, editable plan card (reorder, skip, remove, approve step-by-step, run, rollback) that you review before anything executes. Edit lets approved actions apply directly, still gated by the same per-action approval and risk rules. The AI itself can never switch modes — only you can, in the panel.
  • Word — draft, continue, summarize, rewrite, expand, shorten, outline, extract action items, review, and translate via chat or the ribbon Translate menu. Markdown tables become native Word tables. Track edits inserts/rewrites responses as Word Track Changes, with Accept/Reject controls.
  • Excel — range analysis (`analyze_range`/`get_formula_details`/`add_analysis_column`), formulas, fill-down, table writes, Excel Table creation, conditional formatting (with configurable palette), sorting, filtering, data validation, charts (column/bar/line/pie/scatter/area/doughnut), PivotTables with field config (rows/values/columns/filters), named ranges, duplicate removal, find/replace, case/trim/normalize/text-to-columns, row/column insert/delete/hide, merge/format/autofit/freeze, summary rows, Python `=PY()` (multi-line), themes, sparklines, local import, shapes, workbook rules, highlights — always as previewable cards with Review & Apply. The add-in never writes without explicit approval.
  • PowerPoint — build/update a deck from an outline, review the whole deck (untitled slides, duplicate titles, text-light slides), move slides, create/rename sections, set speaker notes, and insert a local image with accessible alt text.
  • Domain packs and skills — pick general (official letters, minutes, inspection reports, RCA, dashboards) or railway (adds DRM briefings, failure/Pareto analysis, asset health, deficiency tracking, and railway terminology) in Settings. The active pack's skills surface as extra quick-prompt chips in the input area, chosen based on what's currently relevant.
  • Source citations — extracted paragraph, cell, and slide references (e.g. [¶12], Sheet1!B7, [Slide #3: Title]) in the assistant's response are clickable links that jump you straight to that location in the document.
  • DPAPI local storage — your API keys (config.dat), conversation history, and the approved-action log (action-audit.dat) are encrypted for the current Windows user with Windows DPAPI under %LOCALAPPDATA%\MSOfficeAIAssistant.

What is NOT included in this version

  • No Microsoft Graph, SharePoint/OneDrive retrieval, or tenant/enterprise search.
  • No cloud telemetry — the add-in does not phone home; it talks only to the provider you configure.
  • No Outlook integration in the current ribbon/panel.

2. Configure your API key

  1. Open Word, Excel, or PowerPoint and switch to the AI Assistant tab on the ribbon.
  2. Click Configure (or the ⚙️ icon in the top-right of the chat panel).
  3. Choose your Active Provider: Mistral AI, Groq (Ultra-Fast), Google Gemini, or Custom API (OpenAI-compatible / Ollama).
  4. Paste your API key. Use the eye icon to show/hide it while typing.
  5. Choose or type your AI model. For Gemini, click Discover to list models your key can use. For Custom, enter the endpoint URL and any custom HTTP headers (JSON).
  6. Optionally adjust Temperature (0.0 = deterministic, 1.0 = creative) and Max output tokens (256–8192).
  7. Optionally choose a Domain Pack (Skill Pack) — general or railway — to change which quick-prompt skills are surfaced (see §1).
  8. Click Test Connection to verify the key and model work.
  9. Click Save Settings.
Where keys are stored. Settings are saved encrypted with Windows DPAPI (DataProtectionScope.CurrentUser) to %LOCALAPPDATA%\MSOfficeAIAssistant\config.dat. Only the current Windows user on this PC can decrypt it. Your keys never leave this PC except to the provider you chose — the add-in sends them only to that provider's endpoint over HTTPS.

4. Example prompts — Word

Set the Context scope to Selection (default) when the text you want the AI to work on is selected, or Current file to let the assistant read the relevant parts of the whole document. Ribbon buttons use the scope selected in the panel.

Draft a circular — button: Generate, scope: Selection (official source) or Current file Draft a circular on <topic> using only the facts provided. Structure it as: subject, reference, background, instructions, responsibilities, and effective date. Do not invent dates, names, or figures. Flag anything missing in a short note at the end.
Rewrite official English — button: Rewrite, scope: Selection Select the passage, then click Rewrite for "maximum clarity, professional flow, and polished vocabulary". For official correspondence, prefer plain, unambiguous English.
Summarize minutes — button: Summarize, scope: Selection or Current file Provide a concise executive summary of these minutes highlighting key takeaways and action items.
Extract action items — button: Actions, scope: Selection or Current file Extract decisions, action items, owners where explicitly stated, deadlines where explicitly stated, and risks. Do not invent people or dates.
Outline notes — button: Outline, scope: Selection Create a clear, hierarchical outline of the supplied content. Preserve key facts and show the recommended narrative flow.
Bilingual notice EN → Tamil / Hindi — ribbon Translate menu (More group) or chat input, scope: Selection Translate the following text into Tamil accurately and naturally. Output ONLY the clean translated text in Tamil, with no introductory remarks, conversation, or explanation.

Track-edits workflow

  1. In the panel, tick Track edits (available when Word is the active host).
  2. Insert or replace a response (message Insert button). It is applied as Word Track Changes.
  3. Review the tracked edits in Word's Review view, then use the panel's Accept / Reject buttons (selection, or all when nothing is selected), or Word's own Review tab.
  4. Undo undoes the assistant's last Office change.

5. Example prompts — Excel

For Excel, the assistant inspects the worksheet context (explicit column letters and headers). When you ask for a change it returns a structured <excel_actions> block rendered as cards. Nothing is written to the workbook until you click Review & Apply on a card (or Review & Apply All Spreadsheet Actions).

Range analysis — scope: Selection or Current file Analyze the selected range: explain totals, trends, and any anomalies you notice. Reference the column letters and headers.
Formulas — scope: Current file For the sheet's categories, propose SUMIF/COUNTIF/AVERAGEIF formulas that match the category column with wildcards (for example "*non ferrous*") and return them as spreadsheet actions I can review.
Fill-down — scope: Current file Add a flag in column G (G2:G100) that marks rows "High Value" when column F is greater than 50,000, otherwise blank. Return it as an excel action.
Table, validation, chart, PivotTable — scope: Current file Create a PivotTable of total values by item category, and a column chart of totals by month. Return them as excel actions I can review before applying.
Never silent writes. Every proposed change is a previewable action; applying always requires your confirmation. Actions that Excel cannot reliably undo — create table, chart, PivotTable, named range, remove duplicates — are shown with a warning before you apply them. Use Undo after an applied change only for undoable actions.

6. Example prompts — PowerPoint

The Build deck quick chip and the ribbon Slides button are PowerPoint-oriented. When PowerPoint is the active host, the assistant can read the whole deck, sections, slide titles, and speaker notes.

Build a deck — button: Slides or chip Build deck, scope: Selection + file (auto for chip) Create a concise, coherent slide deck from the supplied content. Return numbered slides with a title, 3-5 concise bullets, a Visual suggestion, and Speaker Notes for each slide.
Review weak slides — button: Review or chip Review Review this presentation for story flow and weak slides: flag untitled slides, duplicate titles, and text-light slides, and suggest the most valuable next edits.
Reorganise — chat input Move slide 3 before slide 7, rename section 2 to "Annexures", and add speaker notes to slide 5. Use only safe powerpoint actions.
Insert image — chip Insert image (PowerPoint only) Click Insert image, choose a local file (.png/.jpg/.jpeg/.webp/.bmp). The add-in asks you to confirm and inserts it into the active slide with accessible alt text derived from the file name. The image is a local file — the AI does not generate or fetch images.

9. Indian Railways office workflows

Keep official data in the file. For anything official, set the Context scope so the real data is included — Selection for the authoritative passage, or Current file for a full document/workbook/deck — and attach source documents where needed.
Critical. The assistant must never be allowed to invent people, dates, station/division names, train details, or safety figures. Always instruct it to use only the supplied content, and have a competent human review and sign before any official issue. The add-in itself is instructed to extract owners/deadlines "where explicitly stated" and not to invent them — rely on that, but verify anyway.

9.1 Safety circulars (Word)

Button: Generate (or chat)  |  Scope: Selection (official source text) or Current file  |  Finish: Insert with Track edits, then Accept/Reject after review.

Prompt Draft a railway safety circular on <topic — e.g. monsoon preparedness, level-crossing vigilance, electrical work permits>. Use only the facts in the selection/file. Structure: subject, reference, background, instructions, responsibilities, effective date (state it must be confirmed by the issuing authority), and sign-off. Do not invent dates, names, or figures; list anything missing as "TO BE CONFIRMED".

9.2 Inspection and failure notes (Word)

Button: Summarize, Review, Actions  |  Scope: Selection or Current file

Prompt Summarize the selected inspection notes in neutral, precise official English. Preserve every location, item, and finding; do not add or invent findings. Then list follow-up action items with owners and deadlines only where the notes state them.

9.3 Estimates / BOQ tables (Excel)

Button: chat  |  Scope: Current file  |  Finish: Review & Apply each proposed action — never silent writes.

Prompt Analyse this estimate/BOQ sheet: quantities, rates, and totals by head of account. Propose formulas such as =SUMPRODUCT(quantity, rate) or category totals as spreadsheet actions I can review. Keep all changes bounded to the data rows; start row-level formulas at row 2.
Prompt — validation dropdown Add a data validation dropdown (Open / Closed / Pending) to column E rows 2-100, and a conditional format that flags any line with quantity 0. Return both as excel actions for review.

9.4 MOM and action items (Word)

Button: Actions  |  Scope: Selection or Current file

Prompt Extract the decisions and action items from these minutes. For each action item give: what, who (only if stated), by when (only if stated), and risk. Do not invent people or dates.

9.5 Briefing decks for DRM / GM (PowerPoint)

Button: Build deck chip or Slides ribbon  |  Scope: Selection + file (chip sets this automatically)

Prompt Create a briefing deck for the DRM/GM on <subject> from the supplied content only. Include: agenda, current status, key risks, actions underway, and a clear "ask". For every slide give a title, 3-5 bullets, a Visual suggestion, and speaker notes. Do not invent figures or names.

9.6 Bilingual notices (English → Tamil / Hindi / other)

Where: ribbon Translate menu (More group, 9 languages) or chat input  |  Scope: Selection

Prompt — Tamil Translate the following text into Tamil accurately and naturally. Preserve proper names, designations, station names, and all numbers exactly. Output ONLY the clean translation with no remarks.
Prompt — Hindi Translate the following text into Hindi accurately and naturally. Preserve proper names, designations, station names, and all numbers exactly. Output ONLY the clean translation with no remarks.
Translation is done by the AI model over chat. Confirm bilingual wording with a competent human reviewer before putting a notice on display; machine translation is not a substitute for the officially vetted text.

10. Installation and troubleshooting

Installation

  • Automated: run install.cmd at the repository root — it builds the x86 and x64 assemblies and registers the add-in for the current user. A standalone installer is built from installer/setup-x86.iss and installer/setup-x64.iss with Inno Setup.
  • Works with Office 2010, 2013, 2016, 2019, 2021, and Microsoft 365 (32-bit and 64-bit). Requires .NET Framework 4.8.
  • The User Manual is embedded in the add-in itself, so it is present in every install and opens even if you have never configured a key.

Troubleshooting

See Appendix B of AI_Assistant_SSOT.md in the repository. In brief:

  • Ribbon tab missing: check File → Options → Add-ins → COM Add-ins that the add-in is enabled, and that you registered the correct bitness (x86 for 32-bit Office, x64 for 64-bit Office).
  • API 401: key missing/expired — regenerate and Test Connection in Settings.
  • API 429: rate limit — the add-in retries with backoff; reduce volume or switch model/tier.
  • Logs: %LOCALAPPDATA%\MSOfficeAIAssistant\addin.log (fallback %TEMP%\MSOfficeAIAssistant.log).
